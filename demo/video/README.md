# demo/video/ — 시연영상 템플릿

**복사해서 고쳐 쓰는 것들**이다. 이 폴더의 파일을 그대로 쓰지 말고 자기 작업 폴더로 복사한 뒤
내용을 바꾼다 — 여기 있는 것은 다음 사람도 처음부터 시작하지 않게 하려고 남긴 뼈대다.

```bash
cp -r demo/video ~/my-pqcota-video && cd ~/my-pqcota-video
```

| 파일 | 무엇 | 무엇을 고치나 |
|---|---|---|
| [`script.md`](script.md) | 대본·컷 시트 — 컷별 화면·내레이션·자막 | 분량, 강조할 것, 내레이션 문장 |
| [`edit-sheet.md`](edit-sheet.md) | 편집 지시서 — 타임라인·배속·자막 타이밍 | 클립 실측 길이(다시 찍으면 바뀐다) |

화면 소재를 **어떻게 찍고 영상 파일로 만드는지**는 [`../recording.md`](../recording.md)에 있다.
이 폴더는 그렇게 찍은 클립을 **무슨 순서로 어떻게 붙이는지**를 다룬다.

## 왜 템플릿인가

시연영상은 매번 목적이 다르다 — 대회 출품, 컨퍼런스 발표, 리포 소개. 분량도 강조점도 달라진다.
그래서 **완성본이 아니라 뼈대**를 둔다. 다만 뼈대에 남긴 판단 셋은 목적이 달라도 잘 안 바뀐다:

1. **숫자가 바뀌는 화면 하나에 시간을 몰아준다.** 이 리포에서는 조치 전후의 ML-KEM 개수
   (0개 → 14개 → 0개)다. 기능을 하나씩 소개하면 3분이 그냥 간다.
2. **말로 하는 주장은 화면으로 갚는다.** "정적 스캔이 못 보는 것을 본다"는 문장 대신
   `java.security`에 없는 provider가 관측된 체인에는 있는 두 출력을 나란히 보인다.
3. **못 본 것을 없다고 하지 않는 것도 보인다.** 갭 화면은 짧지만, 이 도구가 무엇을 하지
   않는지를 보이는 유일한 컷이다.

## 되도록 하지 말 것

- **"양자컴퓨터가 곧 모든 암호를 깬다"** 식의 과장. 이 리포는 관측 도구지 위협을 예언하지 않는다.
- **슬라이드만 3분.** 강점은 돌아가는 화면이다. 슬라이드는 도입까지.
- **커맨드 나열.** 진입점을 하나씩 소개하면 정작 근거를 보일 시간이 없다.
