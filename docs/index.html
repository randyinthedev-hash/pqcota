레거시 암호 런타임(OpenSSL · Java JCE/JCA)의 PQC 이관을 관측 → 인벤토리 → 전환물 생성 세 단계로 다루는 오픈소스 플랫폼. An open-source platform that handles the PQC migration of legacy crypto runtimes (OpenSSL · Java JCE/JCA) in three stages: observe → inventory → generate.

이 소프트웨어는 교향악의 단원이지 마에스트로가 아니다 — 무엇을·언제 이관할지 지휘하는 것은 이 도구를 쓰는 사용자다. This software is a player in the orchestra, not the maestro — what to migrate and when is conducted by whoever wields it.

세 단계The three stages

① 관측 (Discovery)① Discovery 실행 중인 시스템이 실제로 어떤 암호를 쓰는지 본다 — 로드된 라이브러리, 살아있는 JVM의 provider 체인, 핸드셰이크에서 협상된 알고리즘. Sees what cryptography a running system actually uses — loaded libraries, a live JVM's provider chain, the algorithms negotiated in the handshake.
② 인벤토리 (Inventory)② Inventory 관측을 어느 노드·어느 앱의 것인지 이어 붙여 쌓는다. append-only라 지난 관측이 덮이지 않고, 스냅샷 사이의 변화를 그대로 낸다. Ties each observation to its node and apps and accumulates them. Append-only, so earlier observations survive and change between snapshots is shown as-is.
③ 전환물 생성 (Provisioning)③ Provisioning 확정된 계획에서 config 조각과 Ansible 플레이북을 만든다 — 적용용과 되돌림용이 함께 나온다. 돌리는 것은 사용자의 Ansible이다. Generates config fragments and Ansible playbooks from a finalized plan — apply and rollback come out together. Running them is your Ansible's job.

써보기Try it

Docker만 있으면 컨테이너로 세운 노드를 실제로 관측하고, 생성한 플레이북을 적용했다가 되돌리는 것까지 한 번에 돈다. With just Docker it stands nodes up as containers, observes them for real, then applies the generated playbook and rolls it back — all in one run. 

git clone https://github.com/randyinthedev-hash/pqcota.git && cd pqcota
./demo/scripts/up.sh && ./demo/scripts/demo.sh   # 정리: ./demo/scripts/down.sh# tear down: ./demo/scripts/down.sh
관측하지 못한 것은 "없음"이 아니다. 수집하지 못한 계층은 갭으로 남기고 증거의 강도를 함께 적는다. 플랫폼은 관측 사실만 내고, 무엇을 언제 바꿀지는 판단하지 않는다. Not seen is not the same as not there. A layer that could not be collected is recorded as a gap, with the strength of the evidence beside it. The platform reports observed facts; what to change, and when, is yours to decide.
