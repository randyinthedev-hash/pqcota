# 오픈소스 활용: 무엇을 쓰고 무엇을 만들지 않았나

[라이선스 정리](licensing.md)가 **라이선스 축**을 본다면, 이 문서는 **선택 축**을 본다. 어느 부문에
무엇을 도입했고 왜 그것인지, 그리고 **만들지 않기로 한 것**과 그 근거를 적는다.

이 리포의 성격상 뒤쪽이 더 중요하다. 관측 도구는 손을 뻗으면 끝이 없어서, 무엇을 만들지 않을지를
정하지 않으면 경계가 없어진다.

> **§ 표기**: 별도 언급이 없으면 [규정서](regulation.md)의 절 번호다.

## 부문별로 무엇을 도입했나

| 부문 | 무엇 | 왜 그것인가 |
|---|---|---|
| **계약·직렬화** | Protobuf · gRPC | 계약이 단일 진실이라 스키마를 코드보다 먼저 고정해야 한다. 하위호환을 **도구가 검사**해 주는 것(`buf breaking`)이 결정적이었다 |
| **표준 산출물** | CycloneDX CBOM (ECMA-424) | 크립토 자산 목록의 표준이 이미 있다. 자체 포맷을 만들면 다른 도구와 못 섞인다 |
| **저장** | PostgreSQL (`pgx`) | append-only 이력과 JSONB가 함께 필요했다. 여러 노드를 시간에 걸쳐 쌓을 때만 쓰고, 한 번 훑는 경로는 저장소 없이 돈다 |
| **OS 프리미티브** | `golang.org/x/sys` | AF_PACKET 원시 소켓. 표준 라이브러리가 덮지 않는 유일한 자리다 |
| **오케스트레이션** | Ansible | 노드 도달은 이미 풀린 문제다. 자체 원격 실행 엔진을 만들지 않는다(§4.4) |
| **코드 생성** | `buf` · `protoc-gen-go` · `protoc-gen-go-grpc` | 생성 결과가 사람마다 달라지지 않게 **버전을 고정**한다 |
| **CI** | GitHub Actions · dependabot | 게이트 열 가지를 밀어 넣을 수 없게 만드는 자리 |
| **그림** | Graphviz | 토폴로지를 DOT로 내고 렌더는 밖에 맡긴다. 산출물(SVG)은 데이터다 |
| **관측 대상 런타임** | OpenSSL · JDK/JCA · Windows CNG · BouncyCastle · oqsprovider | 만드는 것이 아니라 **보는 대상**이다. 각각의 열거 API를 그대로 쓴다 |
| **표준·규격** | NIST FIPS 203/204/205 · RFC 4253 · IANA TLS 코드포인트 | 이름과 판정 기준을 스스로 정하지 않는다 |

## 직접 의존이 다섯뿐이다

```
github.com/jackc/pgx/v5      google.golang.org/grpc      google.golang.org/protobuf
golang.org/x/sys             gopkg.in/yaml.v3
```

관측 대상이 **레거시 서버**라서 그렇다. 소스도 패키지 관리도 기대할 수 없는 구형 호스트에 복사해서
실행하고 지우면 끝이어야 하므로, `CGO_ENABLED=0` 정적 단일 바이너리가 전제가 된다. 의존이 늘면
그 전제가 흔들린다.

그래서 표준 라이브러리로 되는 일은 표준 라이브러리로 한다. ELF 파싱은 `debug/elf`, TLS·SSH 핸드셰이크
파싱은 직접 구현했다. 실제로 10년 된 배포판(CentOS 7·Debian 8)과 musl(Alpine)에서 같은 바이너리
하나가 돈다.

## 만들지 않기로 한 것

이쪽이 이 리포의 실제 설계다. 각 줄에 근거가 붙어 있다.

| 만들지 않은 것 | 대신 | 근거 |
|---|---|---|
| **원격 실행 엔진** | Ansible 등 사용자의 substrate | 노드 도달은 이미 풀린 문제다. 부가가치는 그 위의 게이트·서명·완전성 맵에 있다(§4.4) |
| **소스·아티팩트 CBOM 스캐너** | CBOMkit 등이 낸 표준 CycloneDX를 **받는다** | 소스가 있으면 CI가 이미 보고 있다. 겹쳐 만들 이유가 없고, 파일만 오가므로 라이선스도 전염되지 않는다 |
| **패킷 캡처 라이브러리**(libpcap) | 순수 Go AF_PACKET | 정적 링크를 지키려면 C 의존을 들일 수 없다. 필요한 것은 핸드셰이크 프레임뿐이라 직접 읽는 편이 작다 |
| **외부 조회 도구**(`ldd`·`lsof`·`ss`·`readelf`) | `/proc`·ELF 직접 파싱 | 레거시 서버는 최소 이미지이거나 도구가 없거나 버전이 제각각이다. 기대면 **관측 실패가 환경 탓으로 흩어져** 무엇을 못 봤는지조차 모른다 |
| **JDK 동봉**(jlink 미니 런타임) | Go로 attach를 직접 구현 | attach는 Java 기능이 아니라 OS IPC다. 머신에 JDK가 있으면 그것을 재사용하고, 없어도 붙는다. 번들 크기가 런타임 유무와 무관해진다 |
| **Kotlin·Gradle** | `javac` 하나로 빌드 | 사이드카는 클래스 몇 개다. 빌드 도구를 들이면 기여자의 전제가 늘어난다 |
| **cosign·sigstore** | ed25519 detached 서명 | 투명성 로그와 레지스트리 접근을 전제해 **에어갭과 상충**한다. 이미 있는 서명 인프라와 결이 같고 오프라인에서 완결된다 |
| **동적 추적**(eBPF·ltrace) | 회선에서 실제 협상을 관측 | 침습적이다. 관측 대상이 프로덕션 레거시라 대가가 크다 |
| **판정 엔진·점수화** | 관측 사실만 낸다 | 도구가 대신 판단하면 「🔴는 판정이 아니라 관측」이라는 선이 무너진다 |

## 도입한 것을 어떻게 경계 짓나

**GPL 도구는 프로세스 너머에 둔다.** intake 계약이 그것을 강제한다. GPL collector는 gRPC나 CLI 뒤에
서고, 주고받는 것은 CycloneDX와 Envelope뿐이라 코어 내부 타입이 넘어가지 않는다. 자세한 것은
[라이선스 정리 §5](licensing.md).

**provider 파일은 도구가 주지 않는다.** 어느 provider를 쓸지 고르고 그 파일을 구해 오는 일은 계획을
쓰는 쪽이 한다. 도구가 보장하는 것은 **그 파일이 그대로 배치됐다**(sha256)까지다. FIPS 검증본인지는
검증서가 빌드 단위라 파일만 봐서 알 수 없으므로 확인도 사용자가 한다.

**표준의 이름을 바꾸지 않는다.** TLS 그룹 코드포인트는 IANA 등록값을 그대로 쓰고, 모르는 값은
`unknown(0xNNNN)`으로 적는다. SSH 협상은 RFC 4253의 규칙대로 계산하고 한쪽만 관측했으면 지어내지
않는다. 성숙도 이름은 NIST 표준 문서 번호에 건다.

## 「정상적으로 운영되는 수준」을 무엇이 보증하나

도입한 것이 실제로 물려 돌아가는지는 게이트와 데모가 본다.

| 무엇 | 어떻게 |
|---|---|
| 계약을 깨지 않았나 | `make breaking`이 마지막 릴리스 태그와 대조한다. CI가 돌린다 |
| 생성 코드가 계약과 맞나 | `make generate` 후 차이가 있으면 실패한다 |
| **라이선스 표가 실제 의존과 맞나** | `checkdocs`가 `go list -deps`로 **실제 링크되는 모듈을 버전까지** 대조한다. 표에 없으면 「링크되는데 공개되지 않았다」로, 버전이 다르면 「어느 버전을 검토했나가 거짓이 된다」로 실패한다 |
| 여러 OS·arch에서 서나 | 호스트 + linux/amd64 + windows/amd64 교차 빌드를 매번 확인한다 |
| 물려서 돌아가나 | [데모](../demo/README.md) 6단계가 Ansible·SSH·Postgres·OpenSSL·JVM·Graphviz를 한 줄기로 돌린다. 생성물을 실제 노드에 적용하고 되돌리는 데까지 간다 |

**의존 갱신을 일부러 자동화하지 않았다.** dependabot은 GitHub Actions만 켜 두었다. `go.mod`을 봇이
올리면 위 라이선스 표가 낡는데 봇은 그 표를 고치지 못해 PR이 게이트에서 멈춘다. 직접 의존이 다섯뿐이라
취약점 알림을 받고 손으로 올리는 편이 싸다는 판단이고, 그 이유를 [`dependabot.yml`](../.github/dependabot.yml)에
적어 두었다. 라이선스 표를 **생성**하도록 바꾸면 그때 켤 수 있다.

## 접은 선택지

한 번 검토하고 접은 것들이다. 다시 꺼낼 근거가 생기면 그때 본다.

- **jlink 미니 런타임 아카이브**: 불필요로 결론. 머신의 JDK를 재사용하고, 없으면 Go 네이티브 attach가
  덮는다. attach 가능 JDK가 전무한 환경이 실제로 확인되면 재검토한다.
- **eBPF dynamic-trace**: 침습적이라 하지 않기로 했다. 어휘(`dynamic-trace`)는 계약에 남아 있는데,
  어휘는 계약이고 구현 여부와 별개다.
- **UI**: 리뷰 큐와 확정 버튼이 따라오고, 그 둘은 이 리포가 명시적으로 뺀 것이다. 화면 위에서는
  「여기서 승인도 하자」가 자연스러운 다음 걸음이 되어 관측 도구가 판정 도구가 된다.
